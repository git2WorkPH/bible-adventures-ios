# AI Project Continuity Kit v2

This version adds a generic project-definition layer so the same kit can be reused for different applications, games, APIs, SaaS products, and other software.

## Generic
The skills and workflow are reusable:
- initialization
- assessment
- requirements-to-task planning
- development
- review
- session memory

## Project-specific
Each repository fills in:
- `Documentation/Project/PROJECT.md`
- `Documentation/Project/VISION.md`
- `Documentation/Project/SCOPE.md`
- `Documentation/Project/GLOSSARY.md`
- its own requirements
- architecture decisions
- acceptance criteria

## New-project setup
1. Copy the kit into the repository.
2. Fill in `Documentation/Project/`.
3. Add requirements.
4. Run initialization/assessment.
5. Review findings and decisions.
6. Generate proposed tasks.
7. Explicitly approve tasks.
8. Implement one approved task at a time.
