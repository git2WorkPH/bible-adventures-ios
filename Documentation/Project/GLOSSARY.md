# Project Glossary

| Term | Definition |
|---|---|
| Scripture | Exact quoted approved ESV text, with book/chapter/verse citation and translation label. |
| Interpretation | Explanation or paraphrase beyond direct Bible text, labelled and supported by a reference. |
| Game activity | Invented interactive/visual representation serving learning; its details are not Biblical claims. |
| Story step | Configured dialogue, objective or mini-game controlled by StoryEngine. |
| Activity attempt | One lifecycle instance identified by a token; stale callbacks are rejected. |
| Reflection | Scripture-connected opportunity to consider what the story teaches about GOD. |
| Progress | Recorded gameplay position/completion, never spiritual achievement. |
| Resume | Restore a validated completed-step boundary; unfinished activity begins anew. |
