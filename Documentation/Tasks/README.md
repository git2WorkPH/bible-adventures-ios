# Tasks

Tasks are implementation units derived from approved requirements.

## Task template

```markdown
# <TASK-ID> — <Title>

## Requirement

## Objective

## Scope

## Dependencies

## Expected Changes

## Acceptance Criteria

## Tests / Verification

## Out of Scope

## Status

Proposed | Approved | In Progress | Blocked | Complete
```

A task must not silently expand its parent requirement.
